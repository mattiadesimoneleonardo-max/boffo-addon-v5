# Boffo Addon – Obfuscate-Projekt
1. Diesen Ordner als GitHub-Repo hochladen (alle Dateien reinziehen).
2. Tab **Actions** → *Obfuscate* → Run workflow (läuft auch bei jedem Push).
3. Fertige Jar unter dem Run als Artifact **obfuscated-jar** herunterladen.

Eigene Jar: in `input/` legen. Regeln stehen in `proguard.pro`.
